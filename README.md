## 概要
COACHTECH 教材 Tutorial 9-5「リレーション ハンズオン演習」で作成した成果物です。

## 使用技術
- PHP 8.x
- Laravel 10.x
- Eloquent ORM（hasMany / belongsTo / belongsToMany）
- MySQL

## 学んだこと
- 1対多リレーション（hasMany / belongsTo）と多対多リレーション（belongsToMany）の定義
- リレーション越しのデータアクセス（$post->comments など）
- Eager Loading（with()）でN+1問題を回避する仕組み
